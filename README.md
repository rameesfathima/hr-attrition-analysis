# hr-attrition-analysis
End-to-end HR analytics project predicting employee attrition on IBM HR data (1,470 employees). Covers EDA, statistical tests, 4 ML models with cross-validation (best: Logistic Regression, ROC-AUC 0.83, 72% recall), SHAP explainability, employee risk scoring and an interactive Power BI dashboard. Tools: Python, scikit-learn, XGBoost, SHAP.
